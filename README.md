# Habib's Mockup — Thabo Mokoenaa

Mockup **estudantil** de site de delivery inspirado no layout do [Habib's](https://www.habibs.com.br).
Projeto de portfólio / template para estudante de IA (**Thabo Mokoenaa**).

> **Não é o site oficial.** Sem checkout, sem pagamento, sem afiliação com o Grupo Habib's.

## O que tem

- Home com hero, destaques e seção Habibers
- Cardápio com filtros (combos, bib'sfihas, doces, árabes)
- Páginas Habibers e Restaurantes (conteúdo ilustrativo)
- Botões de pedido/login/app mostram aviso de mockup (sem funcionalidade)

## O que **não** tem (de propósito)

- Logos e fotos oficiais do Habib's (direitos autorais / marca)
- Carrinho, CEP, pagamento ou APIs reais
- Fontes proprietárias Habib's Display (usamos Poppins + Fredoka)

## Como o conteúdo foi obtido

Estrutura, cores de marca e lista de produtos de referência via **Firecrawl** em `habibs.com.br` (`#F0141E`, cardápio, seções Habibers/Delivery).
Assets visuais deste repo são **placeholders originais**.

## Como rodar

Site estático — qualquer servidor local:

```bash
cd habibs-mockup
python3 -m http.server 8080
```

Abra `http://localhost:8080`.
